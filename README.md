# Sahra website

**Open `index.html`** (double-click) or upload the whole folder to any static host (Netlify, Vercel, GitHub Pages, cPanel).
Everything is included offline: Three.js, GSAP, Lenis (smooth scroll) and the fonts. No installation, no build step.

## 1. Get the pictures (two ways, use both)
**A. Automatic, from the links in your chat** (needs internet + Python on your computer)
Double-click **`GET-PICTURES.bat`** (Mac/Linux: `./get-pictures.sh`).
It opens each hotel's official site / Booking / Google / other booking links, collects the real photos, resizes them and
installs them. A summary at the end shows which hotels got photos. Sites that block bots (Booking sometimes, Instagram, TikTok)
will show 0 - use way B for those. Source pages are saved in `assets/hotels/<hotel>/sources.txt`.
Tip: `python tools/fetch_images.py --only tropitel-dahab-oasis --page tropitel-dahab-oasis=https://some-gallery-page`

**B. Your own photos and videos**
Put them in `Data/<Hotel name>/Pic` and `Data/<Hotel name>/Vid` (folders already exist for all 33 hotels), then double-click
**`UPDATE-MEDIA.bat`**. Safe to repeat. (`pip install pillow` and ffmpeg make files smaller, but are optional.)

Photos belong to the hotels or photographers: use them with permission and replace them with your own over time.

## 2. Things to confirm (js/data.js and js/hotels.js)
* `whatsapp` in `js/data.js`: put your real number (international format, no +). Until you do, contact buttons use **email** instead, so nothing points to a wrong number.
* Price ranges are **estimates** (your chat has no prices). Change `tier` per hotel in `js/hotels.js`; add real rates in `from` inside `js/data.js`.
* Activity names such as "Twyalt", "Wade 8zlan", "Wade w4wa4", "G7aza" are kept as you typed them. Fix spelling in `js/data.js`.
* Every place is labelled "Dahab, South Sinai". Change `location` per hotel if needed.

## 3. Files
| File | Purpose |
|---|---|
| `js/data.js` | Brand, price ranges, transport, activities |
| `js/hotels.js` | All 33 hotels/camps and their links (`tier`: budget / comfort / premium / luxury) |
| `js/media.js` | Photos/videos list (generated by the two tools, do not edit) |
| `css/style.css` | Colours (top of file) and layout |
| `js/scene.js` / `js/app.js` | 3D world / interactivity |
| `assets/` | Logo, emblem, favicon, share image, hotel media |

## 4. Publishing
Upload the folder as is. For the contact form and links nothing else is needed.
